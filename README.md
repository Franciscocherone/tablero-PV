# Tablero PV

Web propia de seguimiento de proyectos y boutique — Marketing Posventa.

## Qué es cada archivo
- `index.html` — toda la app (frontend).
- `api/data.js` — función serverless que guarda/lee tus datos en Upstash (Redis).
- `package.json` — dependencia necesaria para esa función.
